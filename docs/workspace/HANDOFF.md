# Übergabevorlage

Für jeden neuen Vorgang kopieren und konkret ausfüllen. Keine Zugangsdaten oder Kundendaten eintragen.

- Vorgang / Datum:
- Ziel und überprüfbare Abnahme:
- Feste Vorgaben:
- Führende Quellen / Pfade:
- Basis-Commit / Arbeitsbranch:
- Bearbeiter:
- Geänderte Dateien und Zweck:
- Ausgeführte Befehle / Ergebnisse / Datum:
- Live geprüft / lokal geprüft / nicht geprüft:
- Offene Fehler, Abhängigkeiten oder Anmeldung:
- Nächster ausführbarer Schritt:
- Integrations- und Veröffentlichungsstatus:
- Erforderliche Nutzerentscheidung (nur falls tatsächlich nötig):

Statuswerte: offen → in Arbeit → geprüft → integriert; blockiert ist ein expliziter
Zwischenstatus mit Grund. „Geprüft“ ersetzt keinen noch offenen produktiven Nachweis.
